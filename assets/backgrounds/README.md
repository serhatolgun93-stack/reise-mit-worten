# Fixed start-screen country backgrounds

The approved start-screen photo mapping is fixed:

- `english_london.png` — London / Big Ben / red double-decker bus
- `turkish_istanbul.png` — Istanbul / Bosphorus / mosque skyline
- `greek_santorini.png` — Santorini / blue domes / sea / pink bougainvillea

These three backgrounds are product-approved and must remain mapped to English, Türkçe and Ελληνικά respectively.

The Flutter start screen should cross-fade the corresponding local asset when the user changes the selected language. Assets are bundled locally so the start experience also works offline.
